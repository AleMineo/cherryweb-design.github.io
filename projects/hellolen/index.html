UX/UI design - HTML/SCSSHelloLen* Cosplay

HelloLen* Cosplay is a personal portfolio website designed to showcase cosplay projects, modeling photography, and artistic collaborations in a visually immersive and responsive experience. The goal was to create a bold, image-driven interface that enhances the visual impact of the content while ensuring performance, usability, and smooth interactions across all devices. The entire design and frontend were crafted manually without wireframes, combining creative direction with custom-coded responsive development.

Role

Tools

01 - Project Vision & Strategy

Designed and built a visual-first portfolio for a cosplay and modeling artist - balancing immersive imagery with clean navigation across mobile, tablet, and desktop.

02 - Design & UX Approach

Worked without wireframes, following an instinctive, visually driven process. Layout decisions focused on:

  • Image-centered compositions that maximize visual storytelling
  • Minimal UI elements to keep focus on the artwork
  • Consistent aesthetic rooted in anime, manga, and cosplay culture

03 - Frontend Development & Interaction

Manually coded in HTML and SCSS with jQuery for interactions, including:

  • Fully responsive layouts across all screen sizes
  • Custom gallery structures and dynamic image handling
  • Smooth transitions and animations without compromising performance

04 - My Role

Owned the full project - design and development - including:

  • UI design, creative direction, and visual composition
  • Manual frontend development in HTML & SCSS
  • Interactive features and responsive behavior via jQuery
